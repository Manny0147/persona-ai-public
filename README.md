# Persona-AI (Public Edition) v1.1

**Clean, shareable, open-source personal social intelligence system.**

Pattern Engine + Trend Engine + Content Engine + strict approval-gated publishing across six platforms.

## Quick Start

```bash
npm install
cp .env.example .env
npm run db:init
npm run dev
```

- Approval Gate: http://localhost:3000/approve
- Health: http://localhost:3000/health
- MCP tools: http://localhost:3000/mcp/tools

See ARCHITECTURE.md for the full system design.
